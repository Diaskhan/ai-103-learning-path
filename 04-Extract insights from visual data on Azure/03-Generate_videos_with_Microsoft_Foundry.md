# Создавайте видеоролики с помощью платформы Microsoft Foundry.

# Введение.

Генеративный искусственный интеллект вышел за рамки работы с текстом и изображениями, охватывая создание видео. С помощью Sora 2, доступного в Microsoft Foundry, вы можете создавать реалистичные и креативные видеоролики на основе текстовых запросов, референсных изображений или путем комбинирования существующих видеоматериалов.

В этом модуле вы узнаете, как развернуть Sora 2, создавать эффективные запросы для генерации видео и разрабатывать приложение на языке Python, которое будет программно создавать видео с использованием SDK от OpenAI.

Примечание.

Мы понимаем, что разные люди предпочитают учиться разными способами. Вы можете пройти этот модуль в формате видео или изучить материалы в виде текста и изображений. Текст содержит более подробную информацию, чем видео, поэтому в некоторых случаях вам может быть полезно использовать его как дополнительный материал к видеолекции.

Sora 2 доступна в Microsoft Foundry и представляет собой комплексную платформу для творчества с превосходным качеством видео и интуитивно понятным интерфейсом.

# Создать видео по заданному описанию.

После того как модель Sora 2 будет развернута, вы сможете начать создавать видео. Процесс создания видео является асинхронным: вы отправляете запрос с вашим описанием и настройками видео, а затем получаете готовое видео, когда оно будет доступно.

## Параметры генерации видео.

Прежде чем составлять запрос, ознакомьтесь с параметрами API, которые определяют характеристики вашего видеовывода:

| Параметр | Описание | Поддерживаемые значения |
| --- | --- | --- |
| **Описание** | Естественное описание вашего видео на естественном языке | Текстовая строка (обязательно) |
| **модель** | Используемая модель | `sora-2` или. `sora-2-pro` |
| **размер** | Разрешение вывода | `1280x720` (пейзаж) `720x1280` (портрет) |
| **секунды** | Продолжительность видео | `4`, `8`или `12` (по умолчанию: 4) |
| **input_reference** | Изображение-образец для первого кадра | Файл в формате JPEG, PNG или WebP. |
| **remix_video_id** | Идентификатор видео, которое будет использовано в качестве основы для создания ремикса | Строка, содержащая идентификатор видео. |

Совет.

Модель лучше всего следует инструкциям в более коротких фрагментах видео. Для достижения наилучших результатов рекомендуется создавать два фрагмента по 4 секунды каждый и объединять их, а не один фрагмент продолжительностью 8 секунд.

## Написание эффективных запросов.

Представьте себе, что вы даете указания оператору. Чем более конкретно вы описываете, какого результата хотите добиться от кадра, тем больше контроля и предсказуемости вы получите. Однако, оставляя некоторые детали открытыми, можно достичь творческих и неожиданных результатов.

### Краткое описание анатомии.

Четкое описание кадра позволяет представить его так, как если бы вы набрасывали его на раскадровке.

- **Композиция кадра:** Укажите тип съемки (общий план, средний план, крупный план) и угол обзора.
- **Описание темы:** Подчеркните ключевые аспекты вашей темы, используя конкретные и запоминающиеся детали.
- **Действие:** Описывайте движения, используя "биты" – небольшие шаги, жесты или паузы.
- **Освещение и цветовая гамма:** Создайте нужную атмосферу с помощью продуманного освещения и выбора основных цветов.
- **Стиль:** Определите эстетику проекта на раннем этапе (например, "фильм в стиле 1970-х годов" или "документальный фильм, снятый с рук").

### Слабые и сильные запросы.

| Слабый запрос | Сильный запрос |
| --- | --- |
| "Красивая улица ночью" | "Мокрый асфальт, пешеходный переход "зебра", неоновые вывески, отражающиеся в лужах" |
| "Человек быстро двигается" | "Велосипедист три раза крутит педали, тормозит и останавливается на переходе." |
| "Кинематографичный вид" | "Объектив с анотоморфной оптикой (коэффициент 2.0x), малая глубина резкости, объемный свет" |

### Пример запроса.

Вот пример хорошо структурированного запроса:

```
In a 90s documentary-style interview, an old Swedish man sits in a study 
and says, "I still remember when I was young."
```

Этот запрос работает по следующим причинам:

- Документальный фильм 90-х задает стиль, поэтому модель выбирает подходящую камеру, освещение и цветовую гамму.
- "Пожилой швед сидит в кабинете" – это описание объекта и обстановки, которое оставляет место для творческой интерпретации.
- Этот диалог предоставляет модели конкретные слова, которые необходимо использовать, чтобы синхронизировать речь с персонажем.

## Использование эталонных изображений.

Для более точного контроля над композицией и стилем используйте... `input_reference` Этот параметр предназначен для предоставления визуальной точки отсчета. Модель использует изображение в качестве отправной точки для первого кадра, а ваш запрос определяет, что произойдет дальше.

Требования к эталонным изображениям:

- Разрешение изображения должно соответствовать целевому размеру видео.`1280x720` или. `720x1280`)
- Поддерживаемые форматы: JPEG, PNG, WebP.

## Переработка существующих видеороликов.

Функция "ремикс" позволяет изменять определенные аспекты существующего видеоролика, сохраняя при этом его основные элементы: переходы между сценами, визуальную компоновку и общую структуру. Это полезно для внесения точных изменений без необходимости создавать проект заново.

Чтобы создать ремикс видео:

1. Создайте видео и запишите его идентификатор (ID). Информация об идентификаторе должна быть получена после завершения задачи.
2. Вызовите конечную точку для создания ремикса, передав оригинальный идентификатор видео и обновленный запрос.
3. Опишите только те изменения, которые вы хотите внести, и сосредоточьтесь на конкретных модификациях.

Для достижения наилучших результатов:

- Ограничьте изменения одним четко сформулированным изменением.
- Укажите конкретно, что нужно изменить: "то же самое освещение, смена объектива на 85 мм" или "та же самая цветовая гамма, но с новыми оттенками: бирюзовый, песочный, ржавый".
- Тщательные и точные правки позволяют сохранить большую точность соответствия исходному тексту.

## Советы для достижения лучших результатов.

- **Стремитесь к простоте:** Каждый кадр должен содержать только одно четкое движение камеры и одно понятное действие объекта съемки.
- **Используйте ритм для обозначения времени:** Вместо фразы "актер проходит через комнату", попробуйте: "актер делает четыре шага к окну, останавливается и отдергивает штору".
- **Соблюдайте последовательность:** Повторно используйте одни и те же фразы для персонажей в разных сценах, чтобы сохранить целостность повествования.
- **Итерация:** Небольшие изменения в настройках камеры, освещении или действиях могут кардинально повлиять на результат. Рассматривайте каждую итерацию как творческую вариацию.

Генерация видео с помощью Sora 2 – это совместный процесс. Вы задаете направление, а модель предлагает различные творческие варианты. Будьте готовы к экспериментам: иногда лучший результат получается уже со второй или третьей попытки.

# Создание видео с использованием языка программирования Python.

Для создания приложений, которые программно генерируют видео, вы можете использовать Python SDK от OpenAI вместе с вашей развернутой версией Sora 2 в Microsoft Foundry. Генерация видео – это асинхронный процесс: вы отправляете задачу, проверяете ее статус и загружаете результат, когда он будет готов.

## Создать видео.

Процесс создания видео состоит из трех этапов: создание задания, проверка его выполнения и загрузка результата.

```
import time

# Create the video generation job
video = client.videos.create(
    model="sora-2",
    prompt="A robot walks through a rainy city street at dusk, neon signs reflecting in puddles",
    size="1280x720",
    seconds="4",
)

print(f"Video creation started. ID: {video.id}")

# Poll for completion
while video.status not in ["completed", "failed", "cancelled"]:
    print(f"Status: {video.status}. Waiting...")
    time.sleep(20)
    video = client.videos.retrieve(video.id)

# Download when complete
if video.status == "completed":
    content = client.videos.download_content(video.id, variant="video")
    content.write_to_file("output.mp4")
    print("Video saved to output.mp4")
```

## Создать видео на основе заданного изображения.

Чтобы использовать изображение в качестве отправной точки, передайте его функции... `input_reference` параметр. Разрешение изображения должно соответствовать целевому размеру видео:

```
video = client.videos.create(
    model="sora-2",
    prompt="The camera slowly pans across the landscape as clouds drift overhead",
    size="1280x720",
    seconds="4",
    input_reference=open("landscape.png", "rb"),
)
```

Примечание.

В настоящее время изображения, содержащие человеческие лица, отклоняются. Вместо этого используйте фотографии пейзажей, объектов или анимированных персонажей.

## Измените существующее видео.

Чтобы изменить существующее видео, сохранив его структуру, используйте метод "ремикса", указав идентификатор (ID) исходного видео.

```
video = client.videos.remix(
    video_id="video_abc123",
    prompt="Change the color palette to warm sunset tones",
)
```

## Обработка состояний задач.

Видеофайлы могут возвращать следующие значения статуса:

| Статус | Описание |
| --- | --- |
| `queued` | Задача ожидает обработки. |
| `in_progress` | Видео генерируется |
| `completed` | Видео готово к скачиванию |
| `failed` | Сбой при генерации (проверьте подробности ошибки) |
| `cancelled` | Заказ отменен |

В случае сбоя выполнения задачи, проверьте... `video.error` для получения подробной информации о том, что пошло не так.

## Основные моменты, которые следует учитывать.

- **Ограничения по количеству одновременных задач:** Вы можете одновременно запускать до двух заданий на создание видео.
- Срок действия заказа: Завершенные видео доступны для скачивания в течение 24 часов.
- **Требования к разрешению:** Изображения-образцы должны иметь точно такое же разрешение, как и целевое видео.
- **Фильтрация контента:** Запросы проходят модерацию по содержанию; вредоносный контент не будет сгенерирован.
