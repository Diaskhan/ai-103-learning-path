# Создавайте изображения с помощью искусственного интеллекта.

# Введение.

С помощью платформы Microsoft Foundry вы можете использовать языковые модели для создания контента на основе запросов, сформулированных естественным языком. Часто создаваемый контент представляет собой текст, написанный естественным языком, но все чаще модели способны генерировать и другие типы контента.

Например, модель OpenAI *gpt-image-1* может создавать оригинальный графический контент на основе описания желаемого изображения.

![Схема запроса, предназначенного для того, чтобы модель создала изображение.](https://learn.microsoft.com/en-us/training/wwl-data-ai/generate-images-azure-openai/media/image-generation.png)

Возможность использования искусственного интеллекта для создания графики имеет множество применений, включая создание иллюстраций или фотореалистичных изображений для статей или маркетинговых материалов, разработку уникальных логотипов для продуктов или компаний, а также в любых ситуациях, когда можно описать желаемое изображение.

В этом модуле вы узнаете, как разрабатывать приложение, которое использует генеративный искусственный интеллект для создания оригинальных изображений.

Примечание.

Мы понимаем, что разные люди предпочитают учиться разными способами. Вы можете пройти этот модуль в формате видео или изучить материалы в виде текста и изображений. Текст содержит более подробную информацию, чем видео, поэтому в некоторых случаях вам может быть полезно использовать его как дополнительный материал к видеолекции.

# Что такое модели генерации изображений?

Сервис Microsoft Foundry поддерживает несколько моделей, способных генерировать изображения, в том числе (но не ограничиваясь ими):

- Серия моделей *gpt-image-1* от компании OpenAI.
- Линейка моделей *FLUX* от компании Black Forest Labs.

Совет.

Посмотреть.[Model catalog](https://ai.azure.com/catalog/models?azure-portal=true)Для получения полного списка доступных моделей посетите платформу Microsoft Foundry. В портале Foundry вы можете использовать фильтры для поиска моделей, предназначенных для преобразования текста в изображение.

Модели генерации изображений – это модели искусственного интеллекта, которые могут создавать графические данные на основе текстового описания. Если говорить проще, вы можете предоставить модели описание, и она сгенерирует соответствующее изображение.

Например, вы можете ввести следующий запрос на естественном языке в модель для генерации изображений:

Робот, поедающий спагетти.

Этот запрос может привести к созданию графического вывода, например, изображения, подобного следующему:

![Иллюстрация робота, поедающего спагетти.](https://learn.microsoft.com/en-us/training/wwl-data-ai/generate-images-azure-openai/media/robot-eating-spaghetti.png)

Сгенерированные изображения являются оригинальными; они не извлекаются из заранее подготовленной базы изображений. Другими словами, эта модель – это не система поиска для *подбора* подходящих изображений, а модель искусственного интеллекта (ИИ), которая *создает* новые изображения на основе данных, на которых она была обучена.

# Изучите модели генерации изображений в портале Microsoft Foundry.

Чтобы поэкспериментировать с моделями генерации изображений, вы можете создать проект в Microsoft Foundry и использовать инструмент "среда для работы с моделями" (model playground) на портале Microsoft Foundry, чтобы отправлять запросы и просматривать полученные сгенерированные изображения.

![Скриншот интерфейса "Изображения" в Azure AI Studio.](https://learn.microsoft.com/en-us/training/wwl-data-ai/generate-images-azure-openai/media/images-playground.png)

При использовании этой платформы (при условии поддержки конкретной модели), вы можете указать разрешение (размер) генерируемых изображений и предоставить эталонное изображение, которое модель будет использовать в качестве основы для создания результата.

# Создайте клиентское приложение, которое использует модель для генерации изображений.

Вы можете использовать специализированный SDK для конкретного языка программирования (например, OpenAI Python SDK или Azure OpenAI .NET SDK) для разработки клиентских приложений, которые используют модели для генерации изображений.

Например, следующий код на языке Python использует API *Images* от OpenAI для отправки запроса модели с целью генерации изображения робота, поедающего гамбургер.

```
# Generate an image
img_results = client.images.generate(
    model="FLUX.1-Kontext-pro",
    prompt="A robot eating a cheeseburger.",
    n=1,
    size="1024x1024",
)

# Save the generated image
image_data = base64.b64decode(img_results.data[0].b64_json)
with open("image.png", "wb") as image_file:
    image_file.write(image_data)
```

В результате получается двоичный поток данных, содержащий запрошенное изображение:

![Иллюстрация робота, поедающего чизбургер.](https://learn.microsoft.com/en-us/training/wwl-data-ai/generate-images-azure-openai/media/robot-eating-cheeseburger.png)
