# Интегрируйте инструменты MCP с агентами искусственного интеллекта Azure.

# Введение.

Искусственные интеллект-агенты способны выполнять широкий спектр задач, но для многих из них все еще требуется взаимодействие с инструментами, находящимися за пределами большой языковой модели. Агентам может потребоваться доступ к API, базам данных или внутренним сервисам. Ручная интеграция и поддержка этих инструментов может быстро стать сложной задачей, особенно по мере роста вашей системы или при частых изменениях.

Серверы протокола контекста модели (Model Context Protocol, MCP) могут помочь решить эту проблему за счет интеграции с агентами искусственного интеллекта. Подключение агента Azure AI к серверу протокола контекста модели (MCP) может предоставить вашему агенту каталог инструментов, доступных по запросу. Такой подход делает ваше решение на основе ИИ более надежным, масштабируемым и простым в обслуживании.

Предположим, вы работаете в розничной компании, специализирующейся на косметике. Ваша команда хочет создать AI-ассистента, который поможет управлять запасами, отслеживая уровень наличия товаров и анализируя последние тенденции продаж. Используя сервер MCP, вы можете подключить этого ассистента к набору инструментов, которые могут проводить оценку складских остатков и предоставлять команде рекомендации.

В этом модуле вы узнаете, как настроить сервер и клиент MCP, а также динамически подключать инструменты к агенту искусственного интеллекта Azure AI Agent. Кроме того, вы попрактикуетесь в создании собственного решения на основе инструментов MCP с использованием сервиса Microsoft Foundry Agent Service.

# Понимание процесса обнаружения инструментов MCP.

По мере того как искусственные интеллект становится все более совершенным, расширяется и спектр инструментов и сервисов, к которым он может получить доступ. Однако регистрация новых инструментов, их управление, обновление и интеграция могут быстро стать сложной и трудоемкой задачей. Динамическое обнаружение инструментов помогает решить эту проблему, позволяя агентам автоматически находить и использовать инструменты во время работы.

## Преимущества протокола контекстного моделирования для искусственного интеллекта.

Протокол контекстного моделирования (Model Context Protocol, MCP) предоставляет ряд преимуществ, которые расширяют возможности и гибкость искусственного интеллекта:

- Динамическое обнаружение инструментов.  
  Искусственные интеллект-агенты могут автоматически получать список доступных инструментов с сервера, а также описания их функций. В отличие от традиционных API, которые часто требуют ручного программирования для каждой интеграции и обновлений при каждом изменении API, MCP позволяет использовать подход "**интегрировать один раз**", что повышает гибкость и снижает затраты на обслуживание.
- **Взаимосовместимость между большими языковыми моделями (LLM):**  
  MCP обеспечивает бесперебойную работу с различными большими языковыми моделями (LLM), позволяя разработчикам **легко переключаться между основными моделями или оценивать их**, чтобы повысить производительность, не требуя при этом переработки существующих интеграций.
- Стандартизированная безопасность.  
  MCP обеспечивает **единый метод аутентификации**, что упрощает безопасный доступ к нескольким серверам MCP. Это устраняет необходимость управления отдельными ключами или протоколами аутентификации для каждого API, что облегчает масштабирование развертывания ИИ-агентов.

## Что такое динамическое обнаружение инструментов?

Динамическое обнаружение инструментов – это механизм, который позволяет агенту искусственного интеллекта находить доступные внешние инструменты без необходимости иметь заранее запрограммированные знания о каждом из них. Вместо того чтобы вручную добавлять или обновлять каждый инструмент, которым может пользоваться агент, он обращается к центральному серверу протокола контекста модели (MCP). Этот сервер действует как живой каталог, предоставляя агенту информацию об инструментах, которые он может понимать и использовать.

Этот подход означает следующее:

- Инструменты можно добавлять, обновлять или удалять централизованно, без изменения кода агента.
- Агенты всегда могут использовать последнюю версию инструмента, что повышает точность и надежность работы.
- Сложность управления инструментами переносится с агента на специализированный сервис.

## Как механизм MCP обеспечивает динамическое обнаружение инструментов?

Сервер MCP предоставляет набор функций, которые представляются в виде инструментов с помощью... `@mcp.tool` Декоратор. Инструменты – это примитивный тип в MCP, который позволяет серверам предоставлять клиентам доступ к выполняемым функциям. Клиент может подключиться к серверу и динамически получать эти инструменты. Затем клиент генерирует обертки для функций, которые добавляются к определениям инструментов Azure AI Agent. Такая структура создает гибкий конвейер:

- Сервер MCP предоставляет доступ к различным инструментам.
- Клиент MCP динамически обнаруживает доступные инструменты.
- Искусственный интеллект Azure использует доступные инструменты для обработки запросов пользователей.

## Зачем использовать динамическое обнаружение инструментов с помощью MCP?

Этот подход имеет ряд преимуществ:

- Масштабируемость: Легко добавляйте новые инструменты или обновляйте существующие, не требуя повторной установки агентов.
- Модульность: Агенты могут оставаться простыми, концентрируясь на делегировании задач, а не на управлении деталями инструментов.
- Удобство обслуживания: Централизованное управление инструментами снижает дублирование и количество ошибок.
- Гибкость: Поддерживает различные типы инструментов и сложные рабочие процессы благодаря объединению функциональных возможностей.

Автоматическое обнаружение инструментов особенно полезно в средах, где инструменты быстро развиваются или где различные команды управляют разными API и сервисами. Использование инструментов позволяет искусственному интеллекту адаптироваться к изменяющимся возможностям в режиме реального времени, безопасно взаимодействовать с внешними системами и выполнять действия, выходящие за рамки простой генерации текста.

# Интегрируйте инструменты для агентов с использованием сервера и клиента управления (MCP).

Для динамического подключения инструментов к вашему агенту Azure AI необходимо сначала настроить работающий протокол контекста модели (Model Context Protocol, MCP). Это включает в себя как сервер MCP, который содержит каталог ваших инструментов, так и клиент MCP, который извлекает эти инструменты и делает их доступными для вашего агента.

## Что такое сервер MCP?

Сервер MCP выступает в качестве реестра инструментов, которые может использовать ваш агент. Вы можете настроить сервер MCP с помощью... `FastMCP("server-name")`Класс FastMCP использует подсказки типов Python и документацию для автоматической генерации описаний инструментов, что упрощает создание и поддержку инструментов MCP. Эти описания затем передаются по протоколу HTTP по запросу клиента. Поскольку описания инструментов хранятся на сервере, вы можете в любое время обновлять или добавлять новые инструменты, не прибегая к изменению или повторной развертыванию вашего агента.

## Что такое клиент MCP?

Стандартный клиент MCP выступает в качестве связующего звена между вашим сервером MCP и сервисом Azure AI Agent. Клиент инициализирует сеанс работы с сервером MCP и устанавливает соединение. После этого он выполняет три основные задачи:

- Определяет доступные инструменты на сервере управления (MCP) с помощью... `session.list_tools()`.
- Создает "заготовки" функций на языке Python, которые служат оболочкой для используемых инструментов.
- Зарегистрируйте эти функции у своего агента.

Это позволяет агенту вызывать любой инструмент, указанный в каталоге MCP, как если бы это была встроенная функция, причем без использования жестко запрограммированной логики.

## Зарегистрируйте инструменты в службе Azure AI Agent.

При инициализации сеанса клиента MCP клиент может динамически получать инструменты с сервера MCP. Инструмент MCP можно запустить, используя... `session.call_tool(tool_name, tool_args)`Инструменты должны быть обернуты в асинхронные функции, чтобы агент мог их вызывать. Затем эти функции объединяются и становятся частью набора инструментов агента, доступного во время выполнения для любых запросов пользователей.

Обзор интеграции инструмента агента MCP.

- Сервер MCP содержит определения инструментов, снабженные... `@mcp.tool`.
- Клиент MCP устанавливает соединение с сервером через протокол MCP.
- Клиент MCP получает доступные определения инструментов с помощью... `session.list_tools()`.
- Каждый инструмент обернут в асинхронную функцию, которая вызывает... `session.call_tool`
- Функциональные возможности этого инструмента объединены в... `FunctionTool` что делает их пригодными для использования агентом.
- The. `FunctionTool` зарегистрирован в наборе инструментов агента.

Теперь ваш агент может получать доступ к вашим инструментам и использовать их посредством взаимодействия на естественном языке. Настроив сервер и клиент MCP, вы обеспечиваете четкое разделение между управлением инструментами и логикой работы агента, что позволяет вашей системе быстро адаптироваться по мере появления новых инструментов.

# Используйте агенты искусственного интеллекта Azure с серверами управления инфраструктурой (MCP).

Вы можете расширить возможности вашего агента Microsoft Foundry, подключив его к серверам протокола Model Context Protocol (MCP). Серверы MCP предоставляют инструменты и контекстную информацию, которые ваш агент может использовать для выполнения задач, тем самым расширяя его функциональность за пределы встроенных функций. Служба Azure AI Agent Service включает поддержку удаленных серверов MCP, что позволяет вашему агенту быстро подключаться к вашему серверу и получать доступ к инструментам.

При использовании службы Microsoft Foundry Agent для подключения к вашему серверу MCP вам не нужно вручную создавать сеанс клиента MCP или добавлять какие-либо дополнительные инструменты в ваш агент. Вместо этого вы создаете объект инструмента MCP, который подключается к вашему серверу MCP. Затем вы передаете информацию о сервере MCP потоку агента при вызове запроса. Это также позволяет вам подключаться и использовать различные инструменты с нескольких серверов в зависимости от ваших потребностей.

## Интеграция удаленных серверов управления политиками (MCP).

Для подключения к серверу MCP вам потребуется:

- Удаленный конечный узел сервера Message Queuing (например,...) <https://api.githubcopilot.com/mcp/>).
- Агент Microsoft Foundry, настроенный для использования инструмента MCP.

Вы можете подключиться к нескольким серверам MCP, добавив их в свой агент как отдельные инструменты. Каждый... `MCPTool` могут включать в себя следующие параметры:

- `server_label`Уникальный идентификатор сервера управления политиками (MCP), например, имя пользователя на платформе GitHub.
- `server_url`URL-адрес сервера управления политиками (MCP).
- `allowed_tools` (необязательно): Список конкретных инструментов, к которым у агента есть доступ.
- `require_approval` (необязательно): Булево значение, определяющее, требуется ли подтверждение пользователя перед выполнением действий с использованием инструментов. Если установлено в "true", агент приостановится и будет ожидать подтверждения, прежде чем выполнять какие-либо действия с инструментами на сервере MCP.

Инструмент MCP также поддерживает пользовательские заголовки, которые позволяют передавать следующую информацию:

- Ключи аутентификации (ключи API, токены OAuth).
- Другие обязательные заголовки для сервера MCP.

## Вызов инструментов.

При использовании объекта Azure MCP Tool вам не нужно оборачивать функции в отдельные инструменты или вызывать их напрямую. `session.call_tool`Вместо этого, инструменты автоматически вызываются по мере необходимости в процессе работы агента. Для автоматического вызова инструментов MCP:

- Создайте... `MCPTool` объект с указанием имени сервера и его URL-адреса.
- Использование. `update_headers` для добавления любых заголовков, необходимых серверу.
- Используйте... `require_approval` параметр, определяющий, требуется ли одобрение. Поддерживаемые значения:
  - `always`Разработчику необходимо предоставить разрешение для каждого вызова. Если значение не указано, используется значение по умолчанию.
  - `never`Одобрение не требуется.
- Создайте агента и добавьте... `MCPTool` относится к списку используемых инструментов.
- Активируйте запрос для агента, и вы должны увидеть результаты работы используемых инструментов в ответе.

Если модель пытается использовать инструмент на вашем сервере управления облачными ресурсами (MCP), для которого требуется подтверждение, вы получите... `mcp_approval_request` в ответе агента. Эта информация включает в себя сведения о том, какой инструмент будет использоваться, и вы можете использовать эти данные для принятия решения об одобрении запроса. Для одобрения отправьте последующее сообщение со следующим содержанием: `mcp_approval_response` объект, который включает в себя... `approval_request_id` ценность и... `approve` булевский.

Интеграция с платформой MCP является важным шагом на пути к созданию более продвинутых и контекстно-ориентированных искусственных интеллектов. По мере развития экосистемы MCP у вас появится еще больше возможностей для внедрения специализированных инструментов в ваши рабочие процессы и предоставления более интеллектуальных и динамичных решений.
