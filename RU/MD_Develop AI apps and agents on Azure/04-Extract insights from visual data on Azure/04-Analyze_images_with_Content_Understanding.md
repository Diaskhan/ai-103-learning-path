# Анализируйте изображения с использованием технологии понимания содержимого.

# Введение.

Изображения, документы и другой неструктурированный контент часто содержат ценную информацию, которую сложно извлечь автоматически. Сервис Azure Content Understanding решает эту проблему, используя генеративный искусственный интеллект для анализа контента и предоставления структурированных данных.

С помощью функции "Понимание содержимого" вы определяете структуру данных, которые хотите получить, а сервис извлекает эти данные из ваших изображений и документов. Полученные результаты готовы к использованию в автоматизированных процессах, аналитических системах и приложениях для поиска.

В этом модуле вы узнаете, как анализировать изображения с использованием технологии понимания содержимого, применяя как готовые, так и собственные инструменты анализа.

Примечание.

Мы понимаем, что разные люди предпочитают учиться разными способами. Вы можете пройти этот модуль в формате видео или изучить материалы в виде текста и изображений. Текст содержит более подробную информацию, чем видео, поэтому в некоторых случаях вам может быть полезно использовать его как дополнительный материал к видеолекции.

# Что такое понимание контента?

Azure Content Understanding – это инструмент платформы Azure, использующий генеративный искусственный интеллект для обработки и извлечения информации из различных типов контента, включая документы, изображения, видео и аудио. Он преобразует неструктурированные данные в структурированный формат, пригодный для использования, который можно интегрировать в процессы автоматизации и аналитики.

## Зачем использовать технологию понимания контента?

Понимание содержания данных позволяет значительно сократить время получения результатов за счет автоматизированной обработки неструктурированных данных. Ключевые преимущества включают в себя:

- **Упрощенные рабочие процессы:** Стандартизирует процесс извлечения и классификации контента из различных источников, объединяя их в единую систему.
- **Простое извлечение данных:** Определите схему для извлечения, классификации или генерации значений полей без использования сложных техник разработки запросов.
- **Повышенная точность:** Использует несколько моделей искусственного интеллекта для одновременного анализа и перекрестной проверки информации.
- **Оценки достоверности и проверка данных:** Обеспечивает точность извлеченных значений, одновременно минимизируя затраты на ручную проверку.
- **Классификация контента:** Разделение документов по типам для оптимизации обработки и направления контента соответствующим аналитическим системам.

## Компоненты для понимания контента.

Система обработки неструктурированного контента состоит из нескольких этапов:

| Компонент | Описание |
| --- | --- |
| **Входные данные** | Исходный контент, включающий документы, изображения, видео и аудиофайлы. |
| **Анализатор** | Определяет способ обработки контента, включая настройки извлечения и структуру данных. |
| **Извлечение информации** | Преобразует неструктурированные данные в нормализованный текст и метаданные с использованием оптического распознавания символов (OCR), транскрипции речи и анализа структуры документа. |
| **Извлечение данных из текста** | Создает структурированные пары "ключ-значение" на основе заданной вами схемы. |
| **Оценки достоверности** | Предоставляют оценки надежности для каждого извлеченного значения поля в диапазоне от 0 до 1. |
| **Обоснование** | Указывает конкретные участки текста, из которых было извлечено каждое значение. |
| **Структурированный вывод** | Окончательный результат в формате Markdown для поисковых запросов или в формате JSON для автоматизированных рабочих процессов. |

## Анализаторы.

Анализаторы являются ключевым компонентом, определяющим способ обработки вашего контента. Система понимания контента предлагает два типа анализаторов:

- **Готовые анализаторы:** Анализаторы, готовые к использованию и предназначенные для решения распространенных задач, таких как обработка счетов, извлечение данных из чеков и анализ работы колл-центров.
- **Индивидуальные анализаторы:** Анализаторы, разработанные вами с использованием собственной схемы полей для решения конкретных бизнес-задач.

При создании анализатора необходимо настроить следующие параметры:

- Тип анализируемого объекта (документ, изображение, аудио- или видеофайл).
- Модели искусственного интеллекта, которые будут использоваться для обработки данных.
- Схема данных, определяющая, какие данные необходимо извлечь.
- Варианты, такие как оценка достоверности и сегментация контента.

## Ограничения по содержанию.

Функция понимания контента включает в себя встроенные механизмы защиты, основанные на принципах ответственного использования искусственного интеллекта. Сервис интегрирован с Azure AI Content Safety для обнаружения и предотвращения распространения вредоносного контента. При обработке контента, пожалуйста, соблюдайте следующие рекомендации:

- Контент фильтруется для удаления материалов, содержащих вредоносный контент, включая насилие, разжигание ненависти и эксплуатацию.
- Функции распознавания лиц позволяют определять различные характеристики лица на видео- и изображениях.
- Обработка биометрических данных требует надлежащего уведомления и согласия от субъектов, чьи данные обрабатываются.

С помощью технологии понимания контента вы можете создавать решения, которые извлекают ценную информацию из различных типов данных, при этом обеспечивая высокое качество и соответствие нормативным требованиям.

# Анализируйте изображения с использованием технологии понимания содержимого.

Функция "Понимание контента" позволяет анализировать изображения для извлечения структурированных данных, выявления визуальных элементов и создания описаний. Вы можете использовать готовые инструменты анализа для типовых задач или создавать собственные инструменты, адаптированные к вашим конкретным потребностям.

## Поддерживаемые форматы изображений.

Функция "Понимание содержимого" поддерживает следующие типы входных изображений:

| Формат | Описание |
| --- | --- |
| **JPEG** | Стандартные фотографии |
| **PNG** | Изображения с поддержкой прозрачности |
| **BMP** | Растровые изображения |
| **TIFF** | Документы высокого качества, полученные в результате сканирования. |
| **HEIF** | Формат изображений высокой эффективности |
| **PDF** | Документы в формате PDF, состоящие из одной или нескольких страниц и содержащие встроенные изображения. |

## Готовые инструменты для анализа изображений.

Функция "Понимание содержимого" включает в себя предустановленные инструменты анализа, оптимизированные для решения распространенных задач обработки изображений:

- **готовый образ:** Общий инструмент для анализа изображений с возможностью извлечения информации и создания описаний объектов на изображениях.
- **Автоматическое распознавание данных из чеков:** Извлечение информации о наименованиях продавцов, перечня товаров, итоговых суммах и датах из изображений чеков.
- **готовый шаблон счета:** Извлечение данных из счета, включая информацию о позициях, суммах и сведениях о поставщике.
- **prebuilt-idDocument**: Извлечение информации из документов, удостоверяющих личность, таких как водительские права и паспорта.

## Определите схему полей для изображений.

Для извлечения конкретной информации из изображений необходимо определить схему полей, которая описывает данные, которые вы хотите получить. Каждое поле может использовать один из трех методов извлечения:

| Метод | Описание | Пример |
| --- | --- | --- |
| **Извлечение данных** | Извлекать значения непосредственно из изображения. | Извлекать текст с этикетки или указателя. |
| **классифицировать** | Распределять контент по заранее определенным категориям | Классифицировать изображение как "поврежденное" или "неповрежденное" |
| **генерировать** | Создавать значения на основе анализа изображения | Генерировать описание сцены |

Вот пример схемы для анализа изображений продуктов:

```
{
  "description": "Product image analyzer",
  "baseAnalyzerId": "prebuilt-image",
  "fieldSchema": {
    "fields": {
      "ProductName": {
        "type": "string",
        "method": "extract",
        "description": "Name of the product visible in the image"
      },
      "Condition": {
        "type": "string",
        "method": "classify",
        "description": "Condition of the product",
        "enum": ["new", "used", "damaged"]
      },
      "Description": {
        "type": "string",
        "method": "generate",
        "description": "Brief description of what the image shows"
      }
    }
  }
}
```

## Проанализировать изображение.

Для анализа изображения с использованием технологии понимания содержимого можно использовать Python SDK, который можно установить следующим образом: `pip` Вот так:

```
pip install azure-ai-contentunderstanding
```

Чтобы отправить запрос к анализирующему сервису, указав идентификатор вашего анализатора и URL-адрес или файл изображения, вы можете использовать код, похожий на следующий пример:

```
from azure.ai.contentunderstanding import ContentUnderstandingClient
from azure.ai.contentunderstanding.models import AnalysisInput, AnalysisResult
from azure.core.credentials import AzureKeyCredential # for key-based authentication
from azure.identity import DefaultAzureCredential # for Entra ID authentication

# Get a client
credential = AzureKeyCredential(key)
client = ContentUnderstandingClient(endpoint={FOUNDRY_ENDPOINT},
                                    credential={KEY_OR_IDENTITY},
                                    api_version="2025-11-01")

# Analyze an image file
with open("my_image.png", "rb") as f:
            file_bytes = f.read()

try:
    poller = client.begin_analyze(
        analyzer_id={ANALYSER_ID},
        inputs=[AnalysisInput(data=file_bytes)],
    )
    # Get results asynchronously from poller
    result: AnalysisResult = poller.result()

    # Display results
    result_str = json.dumps(result.as_dict(), indent=2)
    print (result_str)

except Exception as ex:
    print(f"[Unexpected Error]: {ex}")
    sys.exit(1)
```

После завершения анализа результаты включают извлеченный контент:

- **Описание изображения (в формате Markdown):** Текстовое описание содержимого изображения, полезное для поиска и систем извлечения информации (RAG).
- **поля:** Извлеченные значения полей, соответствующие вашей схеме, каждое со своим уровнем достоверности.
- **Источник:** Информация о том, в какой области изображения было получено каждое значение.

Пример ответа для изображения продукта:

```
{
  "contents": [
    {
      "markdown": "Product label showing 'Contoso Widget Pro' with serial number...",
      "fields": {
        "ProductName": {
          "type": "string",
          "valueString": "Contoso Widget Pro",
          "confidence": 0.95,
          "source": "D(1,100,50,300,50,300,80,100,80)"
        },
        "Condition": {
          "type": "string",
          "valueString": "new",
          "confidence": 0.89
        },
        "Description": {
          "type": "string",
          "valueString": "A silver electronic device in retail packaging with product label visible"
        }
      }
    }
  ]
}
```

## Используйте показатели уверенности.

Каждое извлеченное поле содержит показатель достоверности в диапазоне от 0 до 1:

- **Высокая степень достоверности (0.9 и выше):** Значение можно использовать для автоматизированной обработки с высокой уверенностью.
- **Умеренная уверенность (0,7-0,9):** Рекомендуется проверка человеком для критически важных приложений.
- **Низкая уверенность (менее 0,7):** Рекомендуется ручная проверка.

Используйте показатели уверенности для создания автоматизированных рабочих процессов, которые направляют результаты с низкой степенью достоверности на проверку экспертами, а результаты с высокой степенью достоверности обрабатываются автоматически.

## Советы по улучшению анализа изображений.

- Качество изображения имеет значение: более четкие изображения позволяют получать более точные результаты при извлечении данных.
- **Освещение и контраст:** Убедитесь, что текст и графические элементы хорошо различимы.
- **Единый объект в кадре:** Изображения с одним четко выделенным объектом дают лучшие результаты, чем сцены, перегруженные деталями.
- **Стабильная ориентация:** Изображения, расположенные вертикально, обрабатываются более надежно, чем изображения, подвергшиеся повороту.

Функции анализа изображений, предоставляемые платформой Content Understanding, позволяют преобразовывать визуальный контент в структурированные данные, пригодные для использования в различных бизнес-сценариях, таких как обработка документов, управление запасами, контроль качества и многие другие.
