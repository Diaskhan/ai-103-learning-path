# Разработайте приложение на основе генеративного искусственного интеллекта, использующее возможности компьютерного зрения.

# Введение.

Модели генеративного искусственного интеллекта позволяют создавать приложения, основанные на чат-интерфейсе, которые анализируют входящие данные и реагируют на них. Часто эти данные представляются в виде текстовых запросов, но все большее распространение получают многомодальные модели, способные обрабатывать визуальную информацию.

В этом модуле мы обсудим генеративный искусственный интеллект с возможностью обработки изображений и рассмотрим, как вы можете использовать платформу Microsoft Foundry для создания решений на основе генеративного ИИ, которые реагируют на запросы, содержащие комбинацию текстовых и графических данных.

Примечание.

Мы понимаем, что разные люди предпочитают учиться разными способами. Вы можете пройти этот модуль в формате видео или изучить материалы в виде текста и изображений. Текст содержит более подробную информацию, чем видео, поэтому в некоторых случаях вам может быть полезно использовать его как дополнительный материал к видеолекции.

# Используйте модель с возможностью обработки изображений в портале Microsoft Foundry.

Для обработки запросов, содержащих изображения, необходимо использовать *многомодальную* модель генеративного искусственного интеллекта – то есть модель, которая поддерживает не только текстовый ввод, но и ввод на основе изображений (а в некоторых случаях и аудио). Многомодальные модели, доступные в Microsoft Foundry, включают (среди прочего):

- Microsoft Phi-4, многомодальная версия, предназначенная для выполнения инструкций.
- OpenAI **gpt-4.1**
- OpenAI **gpt-4.1-mini** (модель)

# Разработайте приложение для обмена сообщениями с использованием технологий компьютерного зрения.

Для разработки клиентского приложения, которое взаимодействует с многомодальной моделью посредством чатов на основе анализа изображений, можно использовать те же основные методы, что и для текстовых чатов. Вам потребуется подключение к серверу, где развернута эта модель, и вы будете использовать это соединение для отправки запросов, состоящих из сообщений, которые передаются модели, а также для обработки полученных ответов.

Ключевое отличие заключается в том, что запросы для чата, основанного на визуальном анализе, содержат многокомпонентные сообщения от пользователя, включающие как текстовую часть, так и графическое изображение.

![Схема, иллюстрирующая процесс отправки многокомпонентного запроса в модель.](https://learn.microsoft.com/en-us/training/wwl-data-ai/develop-generative-ai-vision-apps/media/multi-part-prompt.png)

## Отправьте запрос с использованием изображения через API "Ответы".

Чтобы добавить изображение в запрос, используемый с API *Responses*, укажите URL-адрес файла изображения, расположенного в интернете, или загрузите локальный файл изображения, закодируйте его данные в формате Base64 и отправьте URL-адрес в следующем формате: [URL]. `data:image/jpeg;base64,{image_data}` (заменяя "jpeg" на "png" или другие подходящие форматы).

Следующий пример на языке Python демонстрирует, как отправить изображение в запросе, используя API "Ответы":

```
# Read the image data from a local file
image_path = Path("dragon-fruit.jpeg")
image_format = "jpeg"
with open(image_path, "rb") as image_file:
    image_data = base64.b64encode(image_file.read()).decode("utf-8")

data_url = f"data:image/{image_format};base64,{image_data}" # You can also use a web URL

# Send the image data in a prompt to the model
response = client.responses.create(
    model="gpt-4.1",
    input=[
        {"role": "developer", "content": "You are an AI assistant for chefs planning recipes."},
        {"role": "user", "content": [  
            { "type": "input_text", "text": "What desserts could I make with this?"},
            { "type": "input_image", "image_url": data_url}
        ] } 
    ]
)
print(response.output_text)
```

## Отправьте запрос с использованием изображения через API *ChatCompletions*.

При использовании конечной точки Azure OpenAI для отправки запросов к моделям, которые не поддерживают API *Responses*, можно использовать API *ChatCompletions*; вот как это делается:

```
# Read the image data from a local file
image_path = Path("orange.jpeg")
image_format = "jpeg"
with open(image_path, "rb") as image_file:
    image_data = base64.b64encode(image_file.read()).decode("utf-8")

data_url = f"data:image/{image_format};base64,{image_data}" # You can also use a web URL

# Send the image data in a prompt to the model
response = client.chat.completions.create(
    model="Phi-4-multimodal-instruct",
    messages=[
        {"role": "system", "content": "You are an AI assistant for chefs planning recipes."},
        { "role": "user", "content": [  
            { "type": "text", "text": "What can I make with this fruit?"},
            { "type": "image_url", "image_url": {"url": data_url}}
        ] }
    ]
)
print(response.choices[0].message.content)
```
