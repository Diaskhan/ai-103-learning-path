# Разработайте систему анализа текста с использованием сервера Azure Language.

# Введение.

Язык Azure, используемый в инструментах Foundry, предоставляет набор возможностей обработки естественного языка (NLP), которые можно использовать для анализа текста. Эти возможности включают определение языка, распознавание именованных сущностей и извлечение персональных данных.

Хотя вы можете обращаться к этим возможностям по отдельности через REST API или SDK, вы также можете предоставить их агенту искусственного интеллекта с помощью **сервера протокола контекста языковой модели Azure (Azure Language Model Context Protocol - MCP)**. Этот подход позволяет агенту динамически выбирать и использовать подходящий инструмент обработки языка в зависимости от запроса пользователя, без необходимости написания специального кода для каждой отдельной возможности.

Например, представьте, что вы работаете в компании, которой необходимо анализировать отзывы клиентов. Клиенты оставляют отзывы на разных языках, и вашей команде нужно определить язык, на котором написан каждый отзыв, выявить упомянутых людей и места, а также удалить любую личную информацию из этих отзывов. Вместо того чтобы создавать отдельные интеграции для каждой из этих задач, вы можете создать AI-агента, который использует сервер Azure Language MCP для выполнения всех этих операций через единое подключение к инструменту.

В этом модуле вы узнаете, как работает сервер Azure Language MCP, как подключить его к агенту искусственного интеллекта в платформе Microsoft Foundry и как создать клиентское приложение, которое взаимодействует с этим агентом программным путем.

Примечание.

Сервер Azure Language MCP в настоящее время находится на стадии публичного предварительного тестирования. Информация, представленная в этом разделе, может быть изменена.

> Примечание.
>
> Мы понимаем, что разные люди предпочитают учиться разными способами. Вы можете пройти этот модуль в формате видео или изучить материалы в виде текста и изображений. Текст содержит более подробную информацию, чем видео, поэтому в некоторых случаях вам может быть полезно использовать его как дополнительный материал к видеолекции.

# Понимание работы сервера Azure Language MCP.

Сервер Azure Language MCP обеспечивает связь между ИИ-агентами и сервисами Azure Language посредством протокола **Model Context Protocol (MCP)**. Прежде чем углубляться в изучение самого сервера Azure Language MCP, полезно понять, что такое MCP и как он позволяет агентам использовать внешние инструменты.

## Что такое протокол контекста модели?

Протокол контекстного взаимодействия (Model Context Protocol, MCP) — это открытый протокол, определяющий принципы взаимодействия агентов искусственного интеллекта с внешними инструментами, источниками данных и сервисами. MCP использует клиент-серверную архитектуру, состоящую из следующих компонентов:

- **Ведущая программа:** Приложение, в котором работает агент (например, Microsoft Foundry или собственное приложение).
- **Клиент:** Компонент, встроенный в хост-систему, который управляет соединениями с серверами протокола управления (MCP) и обеспечивает взаимодействие с ними.
- **Сервер:** Программа, которая предоставляет инструменты, ресурсы и функции, которые агент может обнаружить и использовать.

Когда агент подключается к серверу MCP, он получает каталог доступных инструментов вместе с описаниями их функций. Затем агент может выбрать подходящий инструмент в зависимости от запроса пользователя. Этот подход называется *динамическим обнаружением инструментов* — агенту не требуется иметь заранее заданные знания о каждом инструменте. Вместо этого, он запрашивает информацию у сервера MCP во время работы, чтобы узнать, какие инструменты доступны.

Ключевым преимуществом платформы MCP для искусственного интеллекта является гибкость. Инструменты можно добавлять, обновлять или удалять на сервере без изменения самого агента. Агент всегда имеет доступ к последним определениям инструментов, что упрощает обслуживание и масштабирование решений, основанных на MCP.

Совет.

Чтобы узнать больше об архитектуре MCP и о том, как создавать собственные интеграции инструментов для работы с MCP, обратитесь к разделу "**".[Integrate MCP Tools with Azure AI Agents](/en-us/training/modules/connect-agent-to-mcp-tools/)Модуль.

## Возможности сервера Azure Language для работы с моделями машинного обучения.

Сервер Azure Language MCP предоставляет возможности обработки естественного языка (NLP) сервиса Azure Language в виде инструментов, которые могут быть использованы любым агентом, совместимым с протоколом MCP. Сервер поддерживает следующие функции анализа текста:

| Возможность | Описание |
| --- | --- |
| **Определение языка** | Определяет язык, на котором написан текст. |
| **Распознавание именованных сущностей** | Определяет и классифицирует объекты в тексте, такие как люди, места, организации, даты и числа. |
| **Удаление персональных данных:** | Обнаруживает и удаляет персонально идентифицируемую информацию (PII), такую как имена, адреса и номера телефонов. |
| **Анализ текста в сфере здравоохранения** | Извлекает и классифицирует медицинские сущности (например, диагнозы, лекарственные препараты и симптомы) из клинических текстов. |

Примечание.

Сервис Azure Language также предоставляет функциональность для анализа тональности текста, автоматического создания кратких изложений, выделения ключевых фраз и выполнения других распространенных задач, связанных с обработкой естественного языка. Эти устаревшие возможности предоставляются для поддержки существующих приложений.

При подключении сервера Language MCP к агенту, агент получает полный список доступных инструментов. На основе запроса пользователя, основная модель агента определяет, какой инструмент (или комбинацию инструментов) следует использовать. Например, если пользователь задает вопрос: "Определите язык, на котором написана эта статья, и сообщите, какие люди в ней упоминаются", агент может одновременно вызвать инструменты для определения языка и распознавания именованных сущностей.

## Как агент выбирает инструменты.

Процесс выбора инструментов происходит следующим образом:

1. Пользователь отправляет запрос агенту.
2. Агент анализирует запрос и определяет, какие задачи необходимо выполнить.
3. Специалист проверяет доступные инструменты MCP и их описания, чтобы найти наиболее подходящий вариант.
4. Агент вызывает выбранный инструмент через сервер управления политиками (MCP), передавая ему соответствующий входной текст.
5. Сервер MCP обрабатывает запрос, используя соответствующую функцию сервиса Azure Language, и возвращает результаты.
6. Агент объединяет полученные результаты и формирует ответ для пользователя на естественном языке.

Это означает, что вам не нужно писать логику маршрутизации для перенаправления запросов к конкретным инструментам. Агент самостоятельно выбирает инструменты, основываясь на описаниях инструментов, которые он получил от сервера управления (MCP).

## Конечная точка сервера MCP.

Сервер Azure Language MCP доступен как удаленный конечный пункт с использованием следующего формата URL-адреса:

```
https://{foundry-resource-name}.cognitiveservices.azure.com/language/mcp?api-version=2025-11-15-preview
```

Заменить. `{foundry-resource-name}` с указанием имени вашего ресурса Foundry (или ресурса Azure Language). Этот конечный пункт предназначен для настройки при подключении сервера MCP к вашему агенту.

Примечание.

Azure Language также предоставляет локальный сервер MCP, который вы можете разместить в своей собственной инфраструктуре. Для получения инструкций по настройке, обратитесь к [ссылке/разделу]. [Azure Language MCP Server quickstart](https://github.com/Azure-Samples/ai-language-samples) в репозитории примеров кода для языка Azure.

# Подключите и используйте сервер Language MCP с агентом.

После того как вы ознакомитесь с возможностями сервера Azure Language MCP, следующим шагом будет подключение его к агенту и начало использования. Это включает в себя создание агента в Microsoft Foundry, подключение инструмента Language MCP, тестирование его в среде разработки агента и, при необходимости, разработку клиентского приложения для программного взаимодействия с агентом.

## Создайте проект и агента Foundry.

Для использования сервера Azure Language MCP вам сначала потребуется проект Microsoft Foundry с развернутой моделью.

1. В течение... [Microsoft Foundry portal](https://ai.azure.com)... создайте новый проект (или используйте существующий).
2. Используйте модель (например, **gpt-4.1**), которую ваш агент будет применять для логических рассуждений и генерации ответов.
3. Создайте агента и предоставьте ему инструкции, описывающие его назначение. Например:

   ```
   You are an AI agent that assists users by helping them analyze and summarize text.
   ```

Теперь агент готов принимать подключения инструментов.

## Подключите сервер Azure Language с сертификатом Microsoft Certified Professional (MCP).

Вы подключаете сервер Azure Language MCP к вашему агенту через страницу "Инструменты" в портале Foundry.

1. В панели навигации выберите раздел "**Инструменты**".
2. Выберите пункт **Подключить инструмент** и выберите **Azure Language в разделе "Инструменты Foundry"** из каталога.
3. Настройте соединение, используя следующие параметры:

   - **Название ресурса Foundry:** Название вашего ресурса Foundry (например, ...). `myproject-resource`).
   - **Аутентификация:** На основе ключей.
   - **Документ, удостоверяющий личность/квалификацию.**`Ocp-Apim-Subscription-Key`Ключ для вашего проекта Foundry.
4. Дождитесь установления соединения, затем выберите пункт "**Использовать в агенте**" и укажите нужного вам агента.

![Скриншот каталога инструментов в портале Foundry, демонстрирующий конфигурацию подключения к сервису Azure Language в разделе "Инструменты Foundry".](https://learn.microsoft.com/en-us/training/wwl-data-ai/develop-text-analysis-agent-language-mcp/media/azure-language-tool-catalog.png)

Теперь агент имеет доступ ко всем инструментам анализа текста, предоставляемым сервером Azure Language.

Совет.

Вы можете найти ключ проекта на главной странице проекта в портале Foundry.

## Обновление инструкций для агентов.

После подключения инструмента Language MCP необходимо обновить инструкции для агента, чтобы он использовал этот инструмент.

```
You are an AI agent that assists users by helping them analyze text. Use the Azure Language tool to perform text analysis tasks.
```

Эта инструкция помогает агенту понять, что он должен использовать подключенный инструмент при обработке запросов на анализ текста.

## Тестирование в среде для разработчиков.

Интерактивная среда для тестирования агентов, доступная в портале Foundry, позволяет вам опробовать работу вашего агента перед его развертыванием в приложении.

Когда вы отправляете запрос, требующий анализа текста, агент:

1. Определяет необходимые задачи (например, определение языка и распознавание сущностей).
2. Вызывает соответствующие инструменты Azure Language для работы с языком.
3. Возвращает объединенный ответ.

При первом использовании агентом инструмента MCP вам будет предложено **подтвердить** использование этого инструмента. Вы можете разрешить использование инструмента только один раз, или выбрать опцию "**Всегда подтверждать использование всех инструментов Azure Language в Foundry Tools**", чтобы избежать будущих запросов на подтверждение.

После того как агент ответит, вы можете просмотреть панель "Журналы", чтобы проверить, какие инструменты были использованы. В журналах отображаются все вызовы инструментов MCP, данные, которые были отправлены, и результаты, которые были возвращены.

## Создайте клиентское приложение.

Хотя среда для тестирования агентов полезна для экспериментов, обычно вам необходимо создать клиентское приложение, которое использует программу-агента программным образом. SDK Microsoft Foundry поддерживает это с помощью API OpenAI Responses.

Для создания клиентского приложения необходимо использовать... `azure-ai-projects` и `azure-identity` пакеты. Общая схема выглядит следующим образом:

1. Создать... `AIProjectClient` используя конечную точку вашего проекта Foundry, а также... `DefaultAzureCredential` (который использует ваши учетные данные Azure CLI в процессе разработки).
2. Получите клиент OpenAI из проекта, вызвав соответствующую функцию. `get_openai_client()`.
3. Звонок. `responses.create()` отправить запрос пользователем к агенту.

Ключевым моментом является то, как вы ссылаетесь на агента – вы указываете его имя в... `extra_body` параметр:

```
response = openai_client.responses.create(
    input=[{"role": "user", "content": user_prompt}],
    extra_body={
        "agent_reference": {
            "name": "Text-Analysis-Agent",
            "type": "agent_reference"
        }
    },
)

print(response.output_text)
```

Агент обрабатывает запрос, вызывает необходимые инструменты управления политиками (MCP), и возвращает результат в... `output_text`Вы также можете просмотреть полный ответ в формате JSON (используя...). `response.model_dump_json()`... чтобы узнать, какие инструменты использовал агент – например, `extract_named_entities_from_text` или. `detect_language_from_text` — вместе с аргументами и результатами работы каждого инструмента.

### Подключите сервер MCP в коде.

Вместо подключения сервера Azure Language MCP через портал Foundry, вы также можете определить подключение к инструменту MCP непосредственно в коде при создании агента. Используйте... `MCPTool` курс от... / группа из... / класс, сформированный на основе... `azure-ai-projects` SDK для указания метки сервера, URL-адреса и разрешенных инструментов.

```
from azure.ai.projects.models import MCPTool

mcp_tool = MCPTool(
    server_label="azure-language",
    server_url="https://{foundry-resource-name}.cognitiveservices.azure.com/language/mcp?api-version=2025-11-15-preview",
    require_approval="always",
)
```

Затем вы проходите... `mcp_tool` при создании агента с помощью SDK. Этот подход полезен, когда вы хотите управлять подключениями к инструментам в рамках кода вашего приложения, а не настраивать их вручную через портал. Вы также можете использовать... `allowed_tools` недвижимость, расположенная по адресу...; собственность, находящаяся по адресу... `MCPTool` ограничить набор конкретных инструментов языка, которые может использовать агент.

## Выбор инструмента с использованием многофункциональных запросов.

Когда запрос пользователя включает в себя несколько задач анализа текста, агент может использовать сразу несколько инструментов за один раз. Например, следующий запрос:

> "Пожалуйста, укажите, какие организации и даты упоминаются в этом отзыве, а также является ли он положительным или отрицательным."

Этот запрос требует как распознавания сущностей, так и анализа тональности. Агент определяет обе задачи и вызывает соответствующие инструменты (…).`extract_named_entities_from_text` и `detect_language_from_text`...и объединяет полученные результаты в один общий ответ.

Каждый вызов инструмента обрабатывается сервером MCP независимо, а агент объединяет полученные результаты в связный ответ для пользователя.
